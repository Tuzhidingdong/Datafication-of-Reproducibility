already-completed real-data Discovery run; **no new Discovery, no re-analysis, and no data modification** was
performed while producing this bundle.

## 3. Files in this package
- `DOR_SCIENTIFIC_DISCOVERY_REPORT.md` — scientific findings and explicit evidence boundaries (authored summary).
- `scientific_questions.csv`, `interaction_candidates.csv`, `excluded_or_unidentifiable.csv`, `evidence_map.csv` — structured summaries authored from DOR outputs.
- `ecorr_icorr_system_level_pairs.csv` — all System-level data points underlying the two opportunities (116 rows: 58 System points x CONDITION/OUTCOME roles).
- `ecorr_icorr_observation_provenance.csv` — all 58 referenced raw Observations with source CSV row locators, source record IDs and DOI.
- `ecorr_icorr_opportunity_evidence.csv` — unmodified export of the 14 `evidence_ledger.jsonl` rows for the two OPP IDs.
- `ecorr_icorr_semantic_mapping.json` — semantic/mapping summary; domain labels are user-provided interpretations, not approved registry facts.
- `matrices/` — Study-level coverage matrices and an SVG overview (structural identifiability only).
- `discovery/` — all 15 native DOR Discovery outputs (unmodified).
- `audit/` — all 6 native DOR CSV/JSON audit outputs (unmodified).
- `redaction_log.csv` — documented redactions of authored files.
- `upload_manifest.json` — SHA-256 of every uploaded file.

## 4. How the new CSV/JSON files were produced
They are **read-only filters and joins** over the already existing `discovery/evidence_ledger.jsonl`, `research_opportunities.json`, the Canonical Bundle's `field_provenance` / `source_locator` metadata, and the existing study DOI/title. No effect size, p/q value, rank, median, orStudy count was recomputed. Fields explicitly marked `canonical_*` or `system_median_used` are existing Runtime-derived values; `original_value` / `original_unit` / `source_locator` are copied from existing source-provenance metadata.

Observation-level `evidence_ids` are empty in the Canonical Bundle, so no PDF/SI locator could be exported; source CSV row locators and DOI are provided instead. Source documents were never opened or dereferenced.

## 5. Which results are Runtime computations vs raw exports
- Runtime-computed: everything under `discovery/` (signals, correlations, opportunities, p/q, bootstrap CIs, evidence ledger) and `audit/`.
- Raw filtered exports: the four `ecorr_icorr_*` files (no new statistics).
- Authored interpretation: the main report and the four structured CSV summaries; these contain Agent scientific review, not Runtime calculations.

## 6. Evidence status
This package is **exploratory review material only**. It does **not** mean the scientific opportunity has passed acceptance. The two FDR-positive opportunities are cross-System, within-Study rank associations with exact per-System value swaps and missing approved semantic metadata; independent domain review is required.

## 7. What is NOT uploaded
No full 66,405-row CSV, no full 2,345-paper JSON, no PDF/SI/images, no credentials/tokens, and no test data were uploaded. Native DOR outputs are kept byte-identical to preserve evidentiary integrity; three authored/native files contained local absolute paths. Two authored files were redacted with documented hashes in `redaction_log.csv`. `discovery/discovery_manifest.json` is intentionally left unmodified and contains a local absolute output path generated by DOR; it is not a secret.

## 8. Reproduction boundary
Re-running Discovery is explicitly out of scope for this package. Any independent reviewer can verify the exported IDs and values against `discovery/` and the documented input hashes.
