# V0.3 — Cross-study reproducibility evaluation

## Purpose

This stage asks whether the modelling relationship can predict an unseen Study, rather than merely reproducing a random row split. It performs nested grouped cross-validation, quantifies Study-level performance dispersion, and records heuristic feature-space support for each held-out Observation.

The evaluation is independent of the single train/validation/test model run. It uses the same task-defined model families and hyperparameter grids, but repeats candidate selection inside each outer fold. It does not use the existing test metrics to select candidates.

## Nested Study-group protocol

The default outer fold count is `min(5, number of eligible Studies)`; at least four eligible Studies are required. Users may request another fold count, but it cannot exceed the eligible Study count.

1. Assign whole canonical Study IDs to deterministic outer folds using the supplied seed.
2. Hold out one outer fold. No Observation from these Studies enters model fitting or inner candidate selection.
3. From the remaining Studies, select a deterministic inner validation subset (approximately 20%, with at least two Studies retained for inner fitting).
4. Fit preprocessing and each candidate on inner-training Studies; choose a candidate using inner-validation metrics only.
5. Refit the chosen model family and hyperparameter on all outer-training Studies.
6. Predict the outer held-out Studies. Each eligible Study is held out exactly once across the full evaluation.

Numeric candidates are the mean baseline and Ridge regression, selected by inner-validation RMSE. Categorical candidates are the majority-class baseline and mixed Naive Bayes, selected by inner-validation macro-F1. Ties follow the deterministic baseline-first rules documented in [the baseline engine contract](V0.3_BASELINE_MODELS.md).

This is nested grouped cross-validation. It is not a second use of the original fixed test set, nor does it replace prospective or independently collected validation.

## Study-level performance and heterogeneity

The report includes pooled out-of-fold metrics, pooled simple-baseline metrics, each outer fold's held-out Study IDs and inner selection trace, and per-Study performance. Regression reports MAE/RMSE/R² where defined and mean signed error per Study. Classification reports accuracy, balanced accuracy, macro-F1, and confusion matrices.

Study-level errors are also summarized as distributions. A spread in per-Study errors or signed bias is evidence of cross-study performance heterogeneity to investigate; it is not automatically a causal explanation. Per-Study R² is null when it is mathematically undefined (for example, a single observation or constant target).

## Applicability-domain heuristic

For each outer held-out Observation, its feature vector is compared with the outer-training reference observations using a mixed-feature nearest-neighbour distance:

- Numeric feature differences are divided by the corresponding outer-training standard deviation (a constant training feature uses scale 1).
- Categorical mismatch contributes 1; an unseen categorical level is explicitly flagged.
- The mixed distance is the root mean square of the per-feature contributions.
- The reference cutoff is the 95th percentile of leave-one-out nearest-neighbour distances within the outer-training observations.

The output flags numeric values outside the outer-training min/max, unseen categories, and held-out observations whose nearest-reference distance exceeds the empirical cutoff. These are **support warnings**, not calibrated probabilities, physical-state boundaries, or universal extrapolation thresholds. A flag means the sample deserves review; absence of a flag does not prove that a mechanistic extrapolation is safe.

## Uncertainty status

This increment does not produce calibrated prediction intervals, posterior uncertainty, or prediction probabilities. It reports the descriptive distribution of nested out-of-fold absolute errors (or classification error indicators). Those values must not be presented as a confidence interval or a calibrated uncertainty estimate. Proper uncertainty calibration is a later component and requires an explicitly justified study-level calibration protocol and enough independent calibration Studies.

## Command

After approving the cohort at G2 and fitting the initial baseline run, execute:

```bash
dor evaluate-reproducibility --cohort-dir 04_modeling/cohort --task modeling_task.json --out-dir 04_modeling/reproducibility_evaluation
```

Optional controls:

```bash
dor evaluate-reproducibility --cohort-dir 04_modeling/cohort --task modeling_task.json --out-dir 04_modeling/reproducibility_evaluation --folds 5 --seed 42
```

The command hash-validates the cohort/task inputs, rechecks row-to-Study/split consistency, leaves the inputs unchanged, and requires a new or empty output directory.

## Output artifacts

- `reproducibility_evaluation.json`: nested fold trace, candidate selection, pooled metrics, per-Study metrics, error/bias distributions, applicability-domain method/counts, and explicit uncertainty status.
- `cross_study_predictions.csv`: one out-of-fold prediction per eligible Observation, with held-out Study and fold identity.
- `study_performance.csv`: per-Study metrics and selected model family for its outer fold.
- `applicability_domain.csv`: per-Observation reference distance, empirical cutoff, support flags, and warning reasons.
- `reproducibility_evaluation_manifest.json`: input/output hashes, fold seed, Study IDs, and evaluation protocol.

Contracts are defined in `schemas/reproducibility_evaluation.schema.json` and `schemas/reproducibility_evaluation_manifest.schema.json`.

## Scientific interpretation limits

- Study grouping only prevents leakage across canonical Study IDs. Duplicate publications, shared datasets, research programmes, or other hidden dependencies must be reconciled before evaluation.
- A small number of Studies produces unstable estimates of heterogeneity. Report fold/Study counts and do not generalize beyond the cohort's support.
- Cross-study predictive stability is not proof of causal mechanism or physical reproducibility.
- The distance heuristic is representation-dependent and inherits the reviewed feature mapping. It cannot reveal unreported latent physical states.
- These diagnostics do not replace external replication, prospective experiments, or direct uncertainty calibration.

## Engineering acceptance

Synthetic tests cover numeric and categorical nested evaluation, one-time outer holdout of every Study, inner/outer leakage prevention, deterministic folds, out-of-domain feature flags, explicit uncalibrated uncertainty status, insufficient Study counts, output protection, and read-only cohort inputs. Full scientific acceptance on the real literature corpus remains reserved for V1.0.
