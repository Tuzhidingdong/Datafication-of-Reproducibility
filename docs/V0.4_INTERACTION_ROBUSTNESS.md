# V0.4 — Interaction robustness by repeated Study-group split seeds

## Purpose

The first interaction screen uses one deterministic seed to assign canonical Studies to outer folds and inner validation groups. A candidate can therefore depend on one particular partition. This increment repeats the complete nested pairwise screen under several distinct seeds and reports how sensitive the candidate labels and predictive gains are to that split randomness.

This is deliberately a narrow robustness check. It does not vary feature encoding, endpoint definitions, model families, candidate feature sets, or the underlying literature corpus.

## Method

Command:

~~~bash
dor assess-interaction-robustness \
  --cohort-dir 04_modeling/cohort \
  --task modeling_task.json \
  --out-dir 04_modeling/interaction_robustness \
  --folds 5 \
  --seeds 11,23,42 \
  --minimum-candidate-run-fraction 0.8
~~~

- At least three unique integer seeds are required.
- Each seed runs the complete existing nested Study-grouped interaction screen independently.
- The same cohort, task, endpoint, candidate pairs, model settings, and fold count are used in every run.
- Every run keeps outer held-out Studies out of inner tuning and model fitting.
- A pair absent from a run's eligible catalogue is marked `NOT_EVALUABLE_IN_THIS_SPLIT`, never assigned zero improvement.
- The default stable-run threshold is 0.8. A pair receives `SEED_STABLE_PREDICTIVE_INTERACTION_CANDIDATE` only when at least that fraction of runs independently receives the original predictive-candidate label and the median mean-fold RMSE improvement is positive.
- Other pairs are labelled `SEED_SENSITIVE_PREDICTIVE_INTERACTION` or `NOT_REPRODUCED_ACROSS_SEEDS`.

The candidate-run fraction is a descriptive frequency across selected split seeds. It is not a probability, confidence level, p-value, or FDR-adjusted statistic.

## Outputs

- `interaction_robustness_report.json`: per-seed nested fold protocols and per-pair sensitivity summaries.
- `interaction_robustness_catalogue.csv`: compact robustness catalogue for downstream review and plotting.
- `interaction_robustness_manifest.json`: exact input/output hashes, seeds, fold count, and claim scope.

The module uses temporary directories for intermediate per-seed runs. Only the consolidated robustness artifacts are retained in the requested output directory. Source cohort and task files remain read-only; output must be new or empty.

## Interpretation limits

- This evaluates sensitivity to deterministic split randomness only.
- It does not establish robustness to alternate feature encodings, alternative model families, endpoint choices, hidden confounding, or independent populations.
- Studies may share authors, materials, protocols, or source datasets; grouping by canonical Study ID does not resolve all dependencies.
- A seed-stable predictive candidate is still not a causal interaction, synergy claim, or mechanism.
- Mechanism claims require independent experimental, theoretical, or computational evidence under the mechanism-evidence contract.

## Engineering tests

Synthetic tests verify seed repeatability, minimum seed count and uniqueness, stable versus seed-sensitive labels, input immutability, and output-directory protection. These are software checks only; full real-corpus acceptance remains reserved for V1.0.
